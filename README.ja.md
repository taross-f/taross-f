## 🔵 Connecting the Dots — Issue を立てるだけ。それ以外の準備は不要。

> *"You can't connect the dots looking forward; you can only connect them looking backwards."* — Steve Jobs

SI、ソーシャルゲーム、IoT・エッジ AI、AI SaaS。振り返ると、これまでの点は 1 本の線につながっていました。
ここから先は、点を打っていくしかありません。**さて、次の点はどこに打ちますか？**

Issue に未来のマス目の座標を書くと、直前の点からあなたの点まで線が引かれます。
線がそれまでの線 — 前に打った点、引かれた線、そして「今」— に触れた瞬間、点がつながります。
その章は殿堂入りし、次の点からはまた「今」から新しい線が始まります。

### 遊び方

1. **[Issue を立てる](https://github.com/taross-f/taross-f/issues/new?template=play.yml)** — ラベル `play` は自動で付きます
2. **x (1〜12) と y (1〜9) の整数 2 つ** を書く。`7 3` でも `7,3` でも `(7, 3)` でも OK
3. 1 分ほどで GitHub Actions が線を引き、盤面と README を更新して Issue に返信します

| ルール | |
|:--|:--|
| マス目 | x = 1〜12 (左から右へ、「今」から遠ざかる方向)、y = 1〜9 (下から上) |
| 線 | その章の直前の点からあなたの点まで引かれます。最初の 1 本は「今」から |
| つながる | 新しく引いた線が、その章で既に引かれたものに触れたら。その章は完成です |
| スコア | 章が完成したときの点の数。自分に触れずに長く伸びるほど高記録 |
| 連投 | 同じ人は 10 分に 1 回まで |

点がどうつながるかは、つながる 1 点が打たれるまで誰にも分かりません。
